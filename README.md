# 📖 Overview

DevTinder is a full-stack developer networking platform inspired by professional networking and collaboration platforms. It enables developers to create technical profiles, discover like-minded developers, send connection requests, collaborate on projects, and build strong technical teams.

The platform focuses on meaningful developer collaboration rather than social networking by matching developers based on skills, interests, experience, and project requirements.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/devtinder.git

cd devtinder
```

---

## Backend Setup

```bash
npm install
```

Create a `.env` file

```env
PORT=7777

DB_CONNECTION_SECRET=your_mongodb_connection_string

JWT_SECRET=your_secret_key
```

Run Backend

```bash
npm run dev
```

---

## Frontend Setup

```bash
cd frontend

npm install

npm run dev
```
